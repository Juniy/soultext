# AI描写人物动作与神态

## 一、AI描写动作与神态的核心思路

### 为什么用AI描写动作与神态
- **细节丰富**：AI能生成大量具体的动作细节
- **避免重复**：提供多样化的描写方式
- **快速生成**：快速生成符合情境的动作描写
- **风格统一**：保持整体风格一致性

### 动作神态描写的核心原则
动作和神态不是独立的描写，而是人物性格、情绪、关系的外在表现。好的动作神态描写应该让读者"看到"人物，而不仅仅是"知道"人物。

### 模板A：情绪性动作生成
```
请为以下情绪生成动作和神态描写：

【角色】[简要描述]
【情绪】[具体情绪]
【场景】[当前场景]
【强度】[情绪强度，1-10]

【生成要求】
1. **面部神态**：
   - 眼神变化
   - 眉毛动作
   - 嘴角变化
   - 脸色变化

2. **身体动作**：
   - 手部动作
   - 身体姿态
   - 脚步移动
   - 习惯性小动作

3. **生理反应**：
   - 呼吸变化
   - 心跳变化
   - 体温变化
   - 肌肉紧张

4. **与环境的互动**：
   - 对周围事物的反应
   - 环境对情绪的影响

【要求】
- 避免直接说"他很生气"
- 通过细节展现情绪
- 符合人物性格
- 字数：[具体字数]
```

### 模板C：互动动作生成
```
请生成以下角色互动的动作描写：

【角色A】[描述]
【角色B】[描述]
【关系】[两人关系]
【场景】[具体场景]
【互动性质】[友好/紧张/暧昧/敌对]

【生成要求】
1. **距离感**：
   - 身体距离
   - 眼神接触
   - 朝向

2. **肢体语言**：
   - 开放还是封闭
   - 主动还是被动
   - 保护性还是攻击性

3. **微表情**：
   - 真实情绪
   - 掩饰的尝试
   - 被对方察觉的程度

4. **动作节奏**：
   - 快还是慢
   - 流畅还是僵硬
   - 协调还是不协调

【要求】
- 展现关系的微妙之处
- 有潜台词
- 推动剧情或展现变化
```

## 三、微表情描写技巧

### 微表情生成
```
请生成以下情绪的微表情描写：

【情绪】[具体情绪]
【掩饰程度】[是否试图掩饰，1-10]
【观察者】[谁在观察]

【生成要求】
1. **眼神**：
   - 瞳孔变化
   - 视线方向
   - 眨眼频率

2. **眉毛**：
   - 眉头动作
   - 眉毛角度
   - 持续时间

3. **嘴角**：
   - 嘴角方向
   - 肌肉紧张
   - 与眼神的协调

4. **其他**：
   - 鼻翼
   - 脸颊
   - 下颌

【要求】
- 五官协调，不割裂
- 真实自然
- 符合掩饰程度
- 观察者能察觉的程度
```

### 神态变化描写
```
请描写以下场景中的神态变化：

【角色】[描述]
【事件】[正在发生什么]
【初始神态】[开始时的神态]
【最终神态】[结束时的神态]

【生成要求】
1. **触发点**：什么引起了变化
2. **变化过程**：
   - 第一阶段：[神态]
   - 第二阶段：[神态]
   - 第三阶段：[神态]
3. **变化速度**：快还是慢
4. **是否被察觉**：他人是否注意到

【要求】
- 变化有层次
- 符合性格逻辑
- 有戏剧张力
```

## 四、不同场景的动作描写

```
请生成以下战斗场景的动作描写：

【角色A】[能力、武器、状态]
【角色B】[能力、武器、状态]
【战斗风格】[快速/力量/技巧/魔法]
【环境】[战斗地点]

【生成要求】
1. **开场动作**：如何开始

【要求】

- 有紧张感和释放感
```

## 五、AI动作神态避坑指南

### 常见错误
1. **过度描写**：每个动作都详细描写
2. **与性格不符**：动作不符合人物性格
3. **缺乏变化**：人物始终一个样子
4. **忽视环境**：动作与环境脱节
5. **节奏混乱**：动作描写破坏节奏

### AI常见问题
1. **模板化**：常见的动作模式
2. **不协调**：动作与情绪不匹配
3. **过度完美**：动作过于流畅
4. **缺乏细节**：动作描写空洞

### 解决方法
- 要求AI加入具体细节
- 要求AI考虑环境因素
- 要求AI控制描写长度
- 人工检查是否符合人物

## 六、实战案例

### 案例1：紧张时的动作
**提示词**：
```
请描写一个角色在面试时的紧张动作：
- 角色：内向的应届毕业生
- 场景：大公司面试
- 要求：通过动作展现紧张，但不让人反感
```

**AI生成要点**：
- 反复整理衣领（寻求控制感）
- 手指轻敲大腿（释放紧张）
- 眼神飘忽但努力集中
- 深呼吸但声音微颤
- 坐下时只坐椅子前三分之一

### 案例2：谎言被揭穿时的神态
**提示词**：
```
请描写一个角色谎言被揭穿时的神态变化：
- 角色：平时自信的人
- 场景：对质现场
- 要求：展现从否认到承认的过程
```

**AI生成要点**：
- 瞬间的瞳孔收缩
- 下意识的否认摇头
- 眼神从坚定到闪躲
- 嘴角从紧绷到松弛
- 最终低下头，肩膀放松
