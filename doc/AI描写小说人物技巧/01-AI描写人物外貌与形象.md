# AI描写人物外貌与形象

## 一、AI描写人物外貌的核心思路

### 为什么用AI描写外貌
- **细节丰富**：AI能生成大量具体的外貌细节
- **避免重复**：提供多样化的描写方式
- **快速迭代**：快速生成多个版本选择
- **风格统一**：保持整体风格一致性

### 外貌描写的目的
外貌描写不是为了让读者知道角色长什么样，而是为了让读者通过外貌感受角色的性格、身份、情绪和状态。

## 二、外貌描写提示词模板

### 模板A：基础外貌生成
```
请为以下角色生成一段外貌描写：

【角色信息】
- 姓名：[姓名]
- 年龄：[年龄]
- 性别：[性别]
- 身份/职业：[身份]
- 性格特点：[性格]

【描写要求】
1. 字数：[具体字数，如200-300字]
2. 重点突出：[需要重点描写的部位或特征]
3. 风格：[文艺/简洁/华丽/写实]
4. 氛围：[需要营造的氛围]

【特殊要求】
- [如有特殊要求，如伤疤、纹身、特殊发型等]
- [需要体现的身份特征]
- [需要暗示的性格特点]

【输出】
直接输出描写段落，不需要额外解释。
```

### 模板B：细节化外貌描写
```
请为以下角色生成详细的外貌描写，要求具体到每个部位：

【角色】[简要描述]

【需要描写的部位】
1. **面部轮廓**：[脸型、线条感]
2. **眼睛**：[眼型、眼神、睫毛、眉毛]
3. **鼻子**：[鼻型、特点]
4. **嘴唇**：[唇形、颜色、表情]
5. **发型**：[发色、长度、造型]
6. **肤色**：[肤色、质感]
7. **身材**：[身高、体型、姿态]
8. **穿着**：[服装风格、配饰]
9. **特殊标记**：[伤疤、痣、纹身等]
10. **整体气质**：[给人的整体感觉]

【要求】
- 每个部位用1-2句话描写
- 通过外貌暗示性格和身份
- 避免过于完美的描述
- 加入一些瑕疵或特点
```

### 模板C：动态外貌描写
```
请生成一段动态的外貌描写，展现角色在[具体场景]中的样子：

【角色】[简要描述]

```

## 三、五官描写技巧

### 眼睛描写
**提示词**：
```
请描写以下类型的眼睛，每种给出一个具体示例：

1. **冷漠疏离型**：眼神淡漠，仿佛看透一切
2. **温柔治愈型**：眼尾微弯带笑，眼神柔和有光
3. **锐利精明型**：眼神如刀，洞察一切
4. **忧郁深沉型**：眼底藏着化不开的愁绪
5. **天真无邪型**：眼神清澈，不谙世事
6. **魅惑勾人型**：眼角微挑，似笑非笑

要求：
- 每个示例50-80字
- 通过眼睛传达性格
- 避免陈词滥调
```

### 表情神态描写
**提示词**：
```
请生成以下情绪的表情描写：

1. **温柔治愈**：眼尾微弯带笑，嘴角轻扬，眼神柔和有光，脸颊淡淡红晕
2. **委屈软糯**：眼眶微红泛湿，鼻尖微蹙，嘴角向下撇，下唇轻抿
3. **惊喜雀跃**：眼睛睁大圆亮，眉毛上扬，嘴巴微张呈小O型
4. **沉静思考**：眉头轻皱，眼神低垂聚焦，嘴唇轻抿，下颌微收
5. **傲娇可爱**：头微侧，眼睛斜睨，嘴角轻撇带点小得意
6. **三分讥笑三分凉薄四分漫不经心**：复杂表情，眼神玩味与疏离

要求：
- 每个表情描写具体生动
- 五官协调统一，不割裂
- 通过表情展现内心
```

### 动作姿态描写
**提示词**：
```
请生成以下类型的动作姿态描写：

【角色】[身份和性格]
【场景】[具体场景]

【需要包含的动作】
1. 习惯性小动作
2. 情绪性动作
3. 身份性动作（与职业相关）
4. 与他人互动的动作

【要求】
- 动作要体现性格
- 动作要有节奏感
- 避免过度描写
- 服务于剧情
```

```
【要求】
```

```
- 字数：[具体字数]
```

## 五、外貌描写的进阶技巧

### 通过他人视角描写
```
请从[另一角色]的视角，描写[目标角色]的外貌：

【观察者】[身份、与目标角色的关系、对目标角色的情感]
【被观察者】[目标角色信息]

【要求】
- 带有观察者的主观色彩
- 通过观察者的情感滤镜
- 展现两人关系
- 暗示剧情发展
```

### 通过环境反射描写
```
请通过环境反射来描写角色外貌：

【角色】[简要描述]
【环境】[镜子、水面、玻璃等]
【场景】[具体情境]

【要求】
- 不直接描写外貌
- 通过反射展现
- 加入环境氛围
- 暗示角色内心
```

### 对比描写
```
请用对比手法描写角色外貌：

【角色A】[描述]
【角色B】[描述]
【对比维度】[外貌、气质、穿着等]

【要求】
- 突出两人差异
- 通过对比展现性格
- 暗示关系或冲突
- 服务于剧情
```

## 六、外貌描写避坑指南

### 常见错误
1. **过度完美**：角色美/帅得不真实
2. **堆砌形容词**：华丽但空洞
3. **与性格不符**：外貌和性格割裂
4. **一次性倾倒**：开篇就把外貌全写完
5. **缺乏变化**：角色始终一个样子

### AI常见问题
1. **模板化**：生成的外貌千篇一律
2. **西化**：默认生成西方面孔特征
3. **不协调**：五官描述互相矛盾
4. **过度详细**：每个部位都详细描写

### 解决方法
- 要求AI加入瑕疵和不完美
- 明确指定东方审美特征
- 要求五官情绪统一
- 控制描写长度和重点

## 七、实战案例

### 案例1：古风女主外貌
**提示词**：
```
请描写一个古风小说的女主角外貌：
- 身份：江湖医女
- 性格：外冷内热，毒舌心善
- 特点：常年与草药打交道，身上有淡淡药香
- 要求：通过外貌暗示身份和性格
```

**AI生成要点**：
- 素衣青衫，不施粉黛
- 指尖有薄茧（常年采药）
- 眼神清澈但带着疏离
- 发间别着一支木簪（实用主义）

### 案例2：现代反派外貌
**提示词**：
```
请描写一个现代商战小说的反派外貌：
- 身份：上市公司CEO
- 性格：表面温文尔雅，内心阴狠毒辣
- 要求：通过外貌暗示双面性格
```

**AI生成要点**：
- 金丝眼镜后的眼神深不可测
- 永远一丝不苟的西装
- 微笑不达眼底
- 左手无名指有道旧疤（暗示过去）
