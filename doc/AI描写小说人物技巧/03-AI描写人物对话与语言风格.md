# AI描写人物对话与语言风格

## 一、AI描写对话的核心思路

### 为什么用AI描写对话
- **千人千面**：为不同角色生成独特语言风格
- **快速生成**：快速生成大量对话内容
- **风格统一**：保持角色语言风格一致性
- **突破卡文**：在卡对话时提供灵感

### 对话描写的核心原则
好的对话不是信息的传递，而是人物性格、关系、冲突的展现。每个角色应该有自己独特的说话方式。

```

- 语言特点：[说话方式]
- 口头禅：[常用语]
- 情绪状态：[当前情绪]

【角色B】
- 姓名：[姓名]
- 身份：[身份]
- 性格：[性格关键词]
- 语言特点：[说话方式]
- 口头禅：[常用语]
- 情绪状态：[当前情绪]

【对话场景】
[时间、地点、背景]

【对话目的】
[这段对话要达成什么效果]

【要求】
1. 每个角色的语言风格明显不同
2. 有潜台词和言外之意

4. 包含动作和表情描写

```

### 模板B：语言风格定义
```
请为以下角色定义详细的语言风格：

【角色】[简要描述]

【语言风格维度】
1. **词汇偏好**：
   - 常用词汇类型
   - 专业术语使用
   - 粗话/文雅程度

2. **句式特点**：
   - 长句还是短句
   - 爱用问句还是陈述句
   - 是否爱用倒装

3. **语气特征**：
   - 正式还是随意
   - 热情还是冷淡
   - 直接还是委婉

4. **口头禅**：
   - 3-5个常用口头禅
   - 使用场景

5. **情绪表达**：
   - 高兴时怎么说
   - 生气时怎么说
   - 紧张时怎么说
   - 撒谎时怎么说

6. **与不同人说话的区别**：
   - 对上级
   - 对下级
   - 对朋友
   - 对陌生人
   - 对敌人

【输出】
详细描述每个维度，并给出示例。
```

## 三、语言风格差异化技巧

### 通过身份定义语言
```
请为以下不同身份的角色定义语言风格：

【角色1】古代侠客
【角色2】现代程序员
【角色3】职场女强人
【角色4】农村老人

【要求】
- 每个角色给出10句典型话语
- 词汇、句式、语气明显不同
- 符合身份和时代背景
- 避免刻板印象，有新意
```

### 通过性格定义语言
```
请为以下不同性格的角色定义语言风格：

【角色1】内向敏感
【角色2】外向豪爽
【角色3】腹黑阴险
【角色4】单纯天真

【要求】
- 同样的话，不同性格怎么说
- 示例：拒绝别人的邀请
- 示例：表达感谢
- 示例：表达愤怒
- 示例：撒谎
```

### 口头禅设计
```
请为以下角色设计口头禅：

【角色】[简要描述]

【要求】
1. 设计3-5个口头禅
2. 每个口头禅说明使用场景
3. 口头禅要符合性格
4. 避免过于常见（如"卧槽"）
5. 有记忆点

【示例格式】
- 口头禅：[内容]
  使用场景：[什么时候说]
  背后心理：[为什么这样说]
```

## 四、对话进阶技巧

### 潜台词生成
```
请为以下对话加入丰富的潜台词：

【表面话题】[对话在谈什么]
【真实意图】[角色真正想表达什么]
【关系背景】[两人之间的关系和过往]

【要求】
1. 表面聊A，实际在说B
2. 通过措辞、停顿、语气暗示
3. 让细心的读者能读懂
4. 避免过于隐晦
5. 生成一段示例对话
```

### 冲突对话生成
```
请生成一段冲突对话：

【冲突类型】[误会/利益/价值观/情感]
【角色A立场】[立场和情绪]
【角色B立场】[立场和情绪]
【关系】[两人关系]

【要求】
1. 冲突逐步升级
2. 有情绪爆发点
3. 有冷静下来的转折
4. 不欢而散或暂时和解
5. 展现人物性格
6. 字数：[具体字数]
```

### 情感对话生成
```
请生成一段情感对话：

【情感类型】[表白/告别/和解/坦白]
【角色A情感】[情感状态和顾虑]
【角色B情感】[情感状态和顾虑]
【阻碍】[什么阻碍了情感表达]

【要求】
1. 情感真挚，不矫情
2. 有犹豫和挣扎
3. 有爆发和释放
4. 通过细节展现情感
5. 避免狗血套路
6. 字数：[具体字数]
```

## 五、AI对话避坑指南

### 常见错误
1. **信息_dump_**：借对话强行解释设定
2. **过于直白**：没有潜台词，像说明书
3. **重复信息**：读者已知的信息反复说
4. **大段说教**：借角色之口讲道理
5. **所有人一个样**：没有区分度

### AI常见问题
1. **模板化**："首先...其次...最后"
2. **过于礼貌**：不符合人物关系
3. **缺乏情绪**：像机器人对话
4. **不协调**：对话与性格设定不符

### 解决方法
- 要求AI加入打断和省略
- 要求AI使用潜台词
- 要求AI展现情绪变化
- 人工检查是否符合人物

## 六、实战案例

### 案例1：职场暗战对话
**提示词**：
```
请生成一段职场暗战对话：
- 角色A：部门经理，表面温和，实际阴狠
- 角色B：下属，知道经理的秘密
- 场景：经理办公室，只有两人
- 表面：讨论项目进度
- 实际：互相试探和威胁
```

**AI生成要点**：
- A："这个项目，你辛苦了。"（暗示"我知道你在做什么"）
- B："应该的，毕竟大家都盯着呢。"（暗示"我也有筹码"）
- 通过项目细节暗示权力斗争

### 案例2：情侣吵架对话
**提示词**：
```
请生成一段情侣吵架对话：
- 表面原因：忘记纪念日
- 实际原因：长期积累的忽视
- 要求：从具体事件上升到情感需求
```

**AI生成要点**：
- 开始："你又忘了！"
- 升级："你根本不在乎我！"
- 转折："我要的不是礼物，是被重视的感觉"
- 和解："我知道，是我忽略了你的感受"
