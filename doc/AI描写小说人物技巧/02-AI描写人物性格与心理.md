# AI描写人物性格与心理

## 一、AI描写性格与心理的核心思路

### 为什么用AI描写性格与心理
- **深度挖掘**：AI能生成多层次的内心活动
- **逻辑自洽**：确保人物行为符合性格逻辑
- **快速构建**：快速生成复杂的心理侧写
- **避免单薄**：防止人物变成标签堆砌

### 性格描写的核心原则
人物的性格不是通过作者直接说出来的，而是通过人物的言行、选择、反应展现出来的。

## 二、性格生成提示词模板

### 模板A：性格深度生成
```
请为以下角色生成详细的性格设定：

【基础信息】
- 姓名：[姓名]
- 年龄：[年龄]
- 身份：[身份]

【核心性格】
[给出3-5个关键词]

【生成要求】
1. **表层性格**：外人看到的性格
2. **深层性格**：真实的内心世界
3. **性格成因**：什么经历造就了这种性格
4. **性格矛盾**：内心的冲突和矛盾
5. **性格缺陷**：明显的缺点和弱点
6. **性格闪光点**：独特的魅力点
7. **性格变化**：在故事中会如何成长

【输出格式】
每个部分用200-300字详细描述。
```

### 模板B：性格与行为逻辑
```
请分析以下性格在特定情境下的行为逻辑：

【性格特点】
[详细描述性格]

【情境列表】
1. 面对弱者求助时
2. 面对强者压迫时
3. 面对利益诱惑时
4. 面对情感纠葛时
5. 面对生死抉择时

【要求】
- 每个情境给出具体反应
- 解释为什么会这样反应
- 体现性格的内在逻辑
- 避免套路化反应
```

### 模板C：心理侧写生成
```
请为以下角色生成深度心理侧写：

【角色】[简要描述]

【心理侧写维度】
1. **童年创伤**：对现在性格的影响
2. **核心恐惧**：最怕失去什么
3. **深层欲望**：真正想要的是什么
4. **自我认知**：如何看待自己
5. **他人认知**：如何看待他人
6. **价值观**：什么最重要
7. **心理防御机制**：如何保护自己
8. **潜意识动机**：自己都没意识到的动机

【要求】
- 深入挖掘，不浮于表面
- 有具体事例支撑
- 逻辑自洽
- 为剧情发展留空间
```

## 三、心理活动描写技巧

### 内心独白生成
```
请为以下场景生成角色的内心独白：

【场景】[具体场景描述]
【角色】[角色信息和当前情绪]
【事件】[正在发生的事情]

【要求】
1. 真实自然，像真实人的想法
2. 有跳跃性，不是线性逻辑
3. 包含矛盾和挣扎
4. 有潜意识层面的内容
5. 长度：[具体字数]

【风格】
- [ ] 碎片化（意识流）
- [ ] 理性分析型
- [ ] 情绪宣泄型
- [ ] 自我对话型
```

### 情绪变化描写
```
请描写角色在以下事件中的情绪变化过程：

【事件】[具体事件]
【角色】[角色信息]
【初始情绪】[开始时的情绪]
【最终情绪】[结束时的情绪]

【要求】
1. 情绪变化有层次，不是跳跃
2. 每个阶段有触发点
3. 通过生理反应展现（心跳、呼吸等）
4. 通过行为变化展现
5. 通过环境映射展现
6. 避免直接说"他很伤心"
```

### 潜意识描写
```
请描写角色的潜意识活动：

【角色】[角色信息]
【当前情境】[正在发生什么]
【表面反应】[角色表现出的反应]

【要求】
1. 展现角色自己都没意识到的想法
2. 通过梦境、闪回、直觉等方式
3. 暗示过去的创伤或欲望
4. 为后续剧情埋下伏笔
5. 与表面反应形成对比
```

## 四、不同性格类型描写

### 内向型性格
```
请生成一个内向型角色的性格描写：

【要求】
- 不是简单的"不爱说话"
- 展现内向者的内心世界
- 描写独处时的状态
- 社交时的不适和应对
- 内心丰富的想象世界
- 对亲密关系的渴望和恐惧
```

### 外向型性格
```
请生成一个外向型角色的性格描写：

【要求】
- 不是简单的"爱说话"
- 展现外向者的能量来源
- 独处时的焦虑和不适
- 社交中的技巧和策略
- 表面热情下的孤独
- 对深度关系的回避或渴望
```

### 复杂型性格
```
请生成一个复杂型角色的性格描写：

【要求】
- 表面和内心反差大
- 有明确的性格成因
- 行为逻辑自洽
- 让读者既理解又意外
- 避免简单的"黑化"或"洗白"
- 展现人性的灰色地带
```

## 五、AI生成性格的进阶技巧

### 用具体事件定义性格
```

- 每个事件展现性格的不同侧面

- 避免套路化选择
- 展现性格的复杂性
```

- 每个维度给出具体表现

### 性格与成长弧线
```

【角色初始状态】[初始性格]

【要求】

4. 成长有代价和牺牲
5. 最终性格仍有缺陷，不是完美
```

## 六、心理描写避坑指南

### 常见错误
1. **直接陈述**："他很伤心" → 应该通过描写展现
2. **过度分析**：人物像心理学家一样分析自己
3. **情绪跳跃**：没有过渡，突然改变情绪
4. **千篇一律**：所有人物的心理活动一个样
5. **脱离情境**：心理活动与当前情境无关

### AI常见问题
1. **过于理性**：AI生成的心理活动过于逻辑化
2. **缺乏深度**：浮于表面，没有潜意识层面
3. **套路化**：常见的心理反应模式
4. **不协调**：心理活动与性格设定不符

### 解决方法
- 要求AI加入矛盾和挣扎
- 要求AI展现潜意识层面
- 要求AI通过具体细节展现心理
- 人工检查逻辑自洽性

## 七、实战案例

### 案例1： PTSD心理描写
**提示词**：
```
请描写一个退伍军人的PTSD心理活动：
- 触发点：听到突然的巨响
- 当前场景：在超市购物
- 要求：展现闪回、生理反应、内心挣扎
```

**AI生成要点**：
- 瞬间的恍惚，回到战场
- 心跳加速，手心出汗
- 强迫自己深呼吸
- 周围人的异样眼光
- 事后的自我厌恶

### 案例2：暗恋心理描写
**提示词**：
```
请描写一个角色暗恋的心理活动：
- 场景：看到暗恋对象和别人说话
- 要求：展现嫉妒、自卑、幻想、自我安慰
```

**AI生成要点**：
- 假装不在意，实则余光一直在看
- 内心的小剧场："他们是不是在约会？"
- 自我贬低："我哪里比得上人家"
- 幻想："如果是我..."
- 自我安慰："反正我也配不上"
