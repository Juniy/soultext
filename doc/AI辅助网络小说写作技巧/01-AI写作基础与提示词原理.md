# AI写作基础与提示词原理

## 一、AI写作的本质认知

### 把AI当成"失忆的天才实习生"
写好提示词的第一法则，是对AI进行准确的拟人化定位。想象一下，你招了一个智商高达160、读过全世界所有书的天才实习生，但他：
- 没有上下文记忆（每次对话都是新的开始）
- 不了解你的个人喜好
- 需要你明确告诉他做什么
- 会犯错，需要检查和修正

### AI写作的核心逻辑
你在搜索引擎里输入"2025年最新智能手机推荐"，这个搜索关键词就是Prompt（提示词），决定了你会看到什么结果。在AI交互中：
- **输入 = Prompt**：你告诉AI你想要它做什么或生成什么内容
- **输出 = 结果**：AI根据你的指令生成内容
- **质量 = 提示词质量**：提示词越精准，输出越符合预期

## 二、有效提示词的通用技巧

### 1. 清晰明确
- 在对话开始时就明确说明你的任务或问题
- 提供上下文和细节，帮助AI理解你的需求
- 将复杂任务分解成更小、更易管理的步骤

### 2. 提供具体信息
- 不要只说"写一个故事"，要说"写一个3000字的都市异能小说开篇"
- 包含关键要素：类型、风格、字数、目标读者
- 给出参考示例，让AI理解你的期望

### 3. 结构化表达
- 使用列表、编号、分段来组织需求
- 明确优先级：哪些是必须的，哪些是可选的
- 使用标记语言（如Markdown）来格式化提示词

### 4. 迭代优化
- 第一次输出 rarely 完美
- 根据输出结果调整提示词
- 逐步细化，直到获得满意结果

## 三、提示词的基本结构

### 基础模板
```
【角色设定】
你是一位[专业身份]，拥有[相关经验]。

【任务描述】
请帮我[具体任务]。

【背景信息】
- 故事类型：[类型]
- 目标读者：[读者群体]
- 风格要求：[风格]

【具体要求】
- 字数：[字数要求]
- 结构：[结构要求]
- 元素：[必须包含的元素]
- 禁忌：[避免出现的内容]

【输出格式】
请以[格式]输出。
```

### 网文专用模板
```
你是一名拥有8年经验的网文小说作家，擅长[类型]小说创作。

请为我创作[具体内容]，要求：
1. 类型：[都市/玄幻/言情等]
2. 风格：[轻松/热血/悬疑等]
3. 字数：[具体字数]
4. 核心设定：[关键设定]
5. 目标读者：[读者群体]

注意：
- 避免[具体禁忌]
- 重点突出[重点要求]
- 保持[风格特点]
```

## 四、提示词优化技巧

### 从模糊到精准
**模糊**：帮我写个小说开头
**精准**：帮我写一个3000字的都市重生小说开篇，主角是35岁破产企业家，重生回到20岁大学时代，风格要热血励志，包含金手指设定，避免俗套的退婚情节

### 添加约束条件
- **字数约束**："控制在2000字以内"
- **风格约束**："语言要口语化，有网感"
- **内容约束**："不要出现血腥描写"
- **结构约束**："按照起承转合四部分来写"

### 使用示例引导
"请参考以下风格：[插入你喜欢的段落]。请按照这种风格创作。"

## 五、常见提示词错误

### 错误1：过于简单
❌ "写个玄幻小说"
✅ "写一个玄幻修仙小说的开篇，主角是废柴流，获得神秘戒指金手指，目标读者是18-25岁男性，风格热血，3000字"

### 错误2：信息过载
❌ 一次性给出20个要求
✅ 分步骤提出，先给核心要求，再逐步细化

### 错误3：缺乏上下文
❌ "继续写"
✅ "请继续写第三章，主角刚获得新能力，需要在战斗中展示，同时引入新反派"

### 错误4：期望过高
❌ 期望AI一次写出完美作品
✅ 把AI当作初稿生成器，后续人工修改

## 六、AI写作的正确心态

### 现实认知
- AI不是"一键生成爆款"
- "日更三万不是梦"是夸张宣传
- AI是辅助工具，不是替代作者

### 正确用法
- AI做它最擅长的事：信息处理、素材整理、重复劳动
- 人做最不可替代的事：人物塑造、情节设计、情绪把控
- 人机协作，各取所长

## 七、提示词进阶技巧

### 角色扮演法
让AI扮演特定角色来获得更专业的输出：
- "你是一位资深网文编辑..."
- "你是一位拥有10年经验的悬疑小说作家..."
- "你是一位擅长人物心理描写的作家..."

### 思维链法
让AI展示思考过程：
- "请先分析这个情节的优缺点，然后再给出修改建议"
- "请列出三种不同的发展方向，并分析各自的利弊"

### 对比法
让AI生成多个版本供选择：
- "请写两个版本，一个热血风格，一个暗黑风格"
- "请提供A方案和B方案，我选其一"

- [ ] 是否提供了足够的背景信息？
- [ ] 是否有明确的字数/格式要求？
- [ ] 是否列出了必须包含的元素？
- [ ] 是否说明了禁忌内容？
- [ ] 是否有参考示例？
- [ ] 是否预留了调整空间？
