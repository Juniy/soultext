# AI辅助章节生成与扩写

## 一、AI章节生成的核心思路

### 人机协作的分工
- **AI做**：信息处理、素材整理、重复劳动、初稿生成
- **人做**：人物塑造、情节设计、情绪把控、最终润色

### 章节生成的适用场景
- 有大纲但不知道怎么展开
- 卡文，知道剧情但写不出来
- 需要快速生成初稿，后续修改
- 想尝试不同的写作风格

## 二、章节生成提示词模板

### 模板A：基于大纲生成章节
```
请根据以下大纲，生成第[章数]章的详细内容：

【小说信息】
- 类型：[类型]
- 风格：[风格]
- 目标读者：[读者群体]

【本章大纲】
[粘贴本章的大纲要点]

【前情提要】
[简要描述上一章的结尾]

【本章要求】
1. 字数：[具体字数，如3000字]
2. 核心事件：[本章要发生的主要事件]
3. 出场人物：[列出出场人物]
4. 情绪走向：[从什么情绪到什么情绪]
5. 爽点设计：[如有，描述爽点]
6. 章节钩子：[结尾的悬念或钩子]

【写作要求】
- 语言风格：[口语化/文艺/热血等]
- 叙事视角：[第一人称/第三人称]
- 节奏要求：[快节奏/慢节奏]
- 避免内容：[具体禁忌]

【输出格式】
直接输出章节正文，不需要额外解释。
```

### 模板B：场景扩写
```
请将以下场景扩写成完整的章节内容：

【场景概要】
[简要描述场景，100字以内]

【扩写要求】
1. 字数：[具体字数]
2. 需要包含的元素：
   - 环境描写
   - 人物对话
   - 动作描写
   - 心理描写
   - 情绪渲染
3. 重点突出：[具体重点]
4. 氛围要求：[紧张/温馨/悬疑等]

【参考风格】
[插入你喜欢的段落作为参考]

请按照以上要求扩写，保持风格一致。
```

### 模板C：对话生成
```
请为以下场景生成人物对话：

【场景背景】
[描述场景和上下文]

【出场人物】
- 人物A：[姓名、性格、目标]
- 人物B：[姓名、性格、目标]

【对话目的】
[这段对话要达成什么效果]

【对话要求】
1. 符合人物性格
2. 有潜台词
3. 推动剧情
4. 包含[具体信息]的传递
5. 避免[具体禁忌]

【输出格式】
只输出对话内容，穿插必要的动作和表情描写。
```

## 三、不同类型章节生成

### 开篇生成
```
请生成一个[类型]小说的开篇（第一章），要求：

【核心设定】
[主角、金手指、世界观等]

【开篇要求】
1. 500字内抓住读者
2. 主角快速登场
3. 核心冲突或危机出现
4. 金手指亮相
5. 给读者继续读的理由

【风格要求】
- 语言：[口语化/热血/悬疑等]
- 节奏：紧凑，不拖沓
- 避免：大段背景介绍

【参考】
类似[某部作品]的开篇风格
```

### 打斗场景生成
```
请生成一场打斗场景，要求：

【对战双方】
- 主角：[能力、状态、目标]
- 对手：[能力、状态、目标]

【打斗要求】
1. 动作连贯，有节奏感
2. 体现双方实力差距或特点
3. 有来有回，不是一边倒
4. 主角最终获胜（或战略性撤退）
5. 打斗中体现人物性格

【情绪要求】
- 紧张感逐步升级
- 关键时刻有转折
- 胜利后有释放感

【字数】[具体字数]
```

### 感情戏生成
```
请生成一段感情戏，要求：

【人物关系】
- 人物A：[对B的感情、顾虑]
- 人物B：[对A的感情、顾虑]

【场景设定】
[时间、地点、氛围]

【感情走向】
[从什么状态到什么状态]

【要求】
1. 情感真挚，不矫情
2. 通过细节展现感情
3. 有冲突或阻碍
4. 符合人物性格
5. 避免狗血套路

【字数】[具体字数]
```

### 打脸爽文场景
```
请生成一个打脸场景，要求：

【反派】
[身份、对主角的轻视、即将付出的代价]

【主角】
[隐藏的实力、打脸的方式]

【场景】
[时间、地点、围观人群]

【爽点设计】
1. 反派先嚣张（建立情绪）
2. 主角隐忍（积累期待）
3. 主角展现实力（释放爽感）
4. 反派震惊（强化爽感）
5. 旁观者反应（放大爽感）

【字数】[具体字数]
```

## 四、AI续写技巧

### 续写提示词
```
请续写以下内容：

【前文】
[粘贴最后一段或最后几段]

【续写要求】
1. 字数：[具体字数]
2. 接下来要发生：[简要描述]
3. 情绪走向：[从什么到什么]
4. 需要引入：[新人物/新信息/新冲突]
5. 结尾要求：[钩子/爽点/悬念]

【风格要求】
[与前文保持一致]
```

### 续写注意事项
1. **保持风格一致**：让AI参考前文风格
2. **控制信息输入**：不要一次性给太多前文
3. **明确方向**：告诉AI接下来要写什么
4. **分段续写**：长章节分几次续写
5. **人工衔接**：检查续写部分与前文的衔接

## 五、章节优化技巧

### 让AI改进已有章节
```
请改进以下章节，要求：

【原文】
[粘贴章节内容]

【改进方向】
1. 增强[具体方面，如节奏/对话/描写]
2. 减少[具体问题，如形容词/说教]
3. 强化[具体元素，如冲突/悬念]
4. 优化[具体部分，如开头/结尾]

【输出要求】
- 直接输出改进后的全文
- 或列出具体修改建议
```

### 常见优化方向
1. **节奏优化**：加快慢节奏段落，放慢关键场景
2. **对话优化**：让对话更自然，更有潜台词
3. **描写优化**：增加感官细节，减少形容词堆砌
4. **冲突优化**：增强冲突强度，增加转折
5. **钩子优化**：强化章节结尾的悬念

## 六、避免AI味的技巧

### 降低机械感的指令
```
请在生成内容时注意：
1. 消除模板化表达
2. 使用口语化语言
3. 加入不完美的细节
4. 让人物有独特说话方式
5. 避免过于工整的排比
6. 加入一些意外的小细节
```

### 具体优化指令
- "把'模板句'变'活人话'"
- "加入一些口语化的表达"
- "让人物的反应不那么完美"
- "加入一些环境的小细节"
- "让对话更自然，像真人说话"

## 七、章节生成的工作流

### 步骤1：准备素材
- 准备好大纲
- 明确本章目标
- 收集参考素材

### 步骤2：生成初稿
- 使用提示词生成章节
- 生成多个版本（可选）
- 选择最佳版本

### 步骤3：人工修改
- 检查逻辑是否通顺
- 调整节奏和情绪
- 优化对话和描写
- 强化爽点和钩子

### 步骤4：AI辅助润色
- 让AI检查语法和错别字
- 让AI优化特定段落
- 让AI提供修改建议

### 步骤5：最终定稿
- 通读全章，确保流畅
- 检查前后衔接
- 确认符合大纲
- 发布或保存

## 八、章节生成工具推荐

### AI写作工具
- **91写作**：专业AI小说创作平台，一键生成全篇

### 通用AI模型
- **ChatGPT**：创意性强，适合发散
- **DeepSeek**：逻辑性强，适合结构
- **Claude**：文风细腻，适合润色
- **豆包**：中文优化好，适合网文
