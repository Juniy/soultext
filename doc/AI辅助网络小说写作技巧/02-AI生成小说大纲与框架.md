# AI生成小说大纲与框架

## 一、AI大纲生成的优势

### 为什么用AI生成大纲
- **速度快**：几分钟生成完整大纲框架
- **思路广**：提供多种可能性，打破思维定式
- **结构稳**：确保大纲逻辑完整、结构合理
- **可迭代**：快速修改调整，找到最佳方案

### AI大纲生成的适用场景
- 只有一个核心梗，需要扩展成完整故事
- 卡在中间，不知道怎么衔接情节
- 想尝试不同类型，快速生成多个方案
- 需要检查现有大纲的逻辑漏洞

## 二、大纲生成提示词模板

### 模板A：基础大纲生成
```
你是一名拥有8年经验的网文小说作家，擅长[类型]小说创作。

请为以下核心梗生成一份详细的小说大纲：

【核心梗】
[描述你的核心创意，100-200字]

【要求】
1. 大纲应包含至少20个章节标题和副标题
2. 涵盖故事的起承转合
3. 每个主要情节点包含：事件、冲突、情绪走向
4. 标注爽点和高潮的位置
5. 包含主要人物的成长弧线

【输出格式】
使用Markdown格式，层次分明，便于阅读。
```

### 模板B：三幕式大纲
```
请为以下故事生成三幕式结构大纲：

【故事核心】
[一句话概括故事]

【第一幕：铺垫】（占比20-25%）
- 需要包含：日常世界、冒险召唤、拒绝召唤、遇见导师、跨越门槛

【第二幕：对抗】（占比50-60%）
- 需要包含：考验与敌人、深入洞穴、严峻考验、获得奖赏

【第三幕：结局】（占比20-25%）
- 需要包含：归途、复活、携万能药归来

【额外要求】
- 每个情节点标注预估字数
- 标注情绪曲线（压抑/释放）
- 标注伏笔位置和回收方式
```

### 模板C：细纲生成
```
基于以下粗纲，请生成详细的章节细纲：

【粗纲】
[粘贴你的粗纲内容]

【细纲要求】
每章包含：
1. 章节标题
2. 核心事件（100字以内）
3. 出场人物
4. 冲突类型（内在/外在）
5. 情绪走向
6. 章节钩子
7. 爽点设计（如有）
8. 伏笔设置（如有）

【字数要求】
每章细纲控制在200-300字。
```

## 三、不同类型大纲生成

### 玄幻/修仙大纲
```
请生成一个玄幻修仙小说的大纲，要求：
- 修炼体系完整（境界划分清晰）
- 宗门势力错综复杂
- 主角有明确的成长路线
- 包含秘境探索、宗门大比、跨界战争等经典元素
- 爽点分布合理
```

### 都市/职场大纲
```
请生成一个都市职场小说的大纲，要求：
- 贴近现实，有共鸣感
- 主角有明确的职业目标
- 包含职场斗争、感情线、家庭线
- 金手指设定合理（如重生、系统、异能）
- 打脸情节自然不突兀
```

### 悬疑/推理大纲
```
请生成一个悬疑推理小说的大纲，要求：
- 核心谜题设计精巧
- 线索分布合理，有误导有真相
- 反转有铺垫，逻辑自洽
- 人物动机充分
- 结局既出人意料又在情理之中
```

### 言情/甜宠大纲
```
请生成一个言情小说的大纲，要求：
- 男女主相遇有戏剧性
- 感情发展有层次（相识→相知→相爱→考验→圆满）
- 有外部阻力（家庭、误会、第三者等）
- 甜虐比例适中
- HE结局，过程可虐
```

## 四、大纲优化技巧

### 与AI协作优化大纲
1. **初稿生成**：用提示词生成初版大纲
2. **问题诊断**：让AI分析大纲的潜在问题
   ```
   请分析以下大纲的潜在问题：
   - 逻辑漏洞
   - 节奏问题
   - 人物动机是否合理
   - 爽点是否足够
   ```
3. **针对性修改**：根据诊断结果调整
4. **反复迭代**：直到大纲完善

### 大纲检查清单
- [ ] 主角目标是否清晰？
- [ ] 核心冲突是否强烈？
- [ ] 人物成长弧线是否完整？
- [ ] 节奏是否有起伏？
- [ ] 爽点分布是否合理？
- [ ] 伏笔是否记得回收？
- [ ] 结局是否令人满意？
- [ ] 每章是否有钩子？

## 五、AI大纲工具推荐

### 专业AI写作工具
- **91写作**：基于Vue 3架构的专业AI小说创作平台
- **笔灵AI**：输入简单设定即可生成完整章节
- **茄子小说写作助手**：辅助扩细纲，生成每章建议
- **墨者**：专业写作软件，集成AI辅助

### 通用AI模型
- **ChatGPT（OpenAI）**：创意性强，适合脑洞发散
- **DeepSeek**：逻辑性强，适合大纲结构
- **Claude**：文风细腻，适合人物和情感
- **豆包**：中文优化好，适合网文风格

### 工具选择原则
1. **大纲生成**：选逻辑性强的（DeepSeek、ChatGPT）
2. **人物设定**：选细腻的（Claude）
3. **章节扩写**：选网文风格好的（豆包、国产AI）
4. **润色修改**：选文学性强的（Claude）

## 六、人机协作的大纲流程

### 步骤1：人工构思核心
- 确定核心梗
- 确定主角人设
- 确定故事类型和风格
- 确定目标读者

### 步骤2：AI生成初稿
- 用提示词生成大纲框架
- 生成多个版本供选择
- 选择最符合预期的版本

### 步骤3：人工筛选调整
- 删除不合理的部分
- 调整情节顺序
- 补充个人创意
- 强化核心卖点

### 步骤4：AI细化完善
- 生成细纲
- 补充人物小传
- 设计关键场景
- 检查逻辑漏洞

### 步骤5：人工最终定稿
- 通读全纲，确保流畅
- 标注重点章节
- 制定写作计划
- 开始正式写作

## 七、避坑指南

### 不要完全依赖AI大纲
- AI生成的大纲可能套路化
- 缺乏个人风格和创意
- 需要人工注入灵魂

### 避免过度规划
- 大纲到章节级别即可
- 细节留给写作时发挥
- 保持灵活性

### 注意AI的局限性
- AI可能生成不合理的情节
- 人物动机可能不够深入
- 需要人工检查和修正

## 八、实战案例

### 案例：从核心梗到大纲
**核心梗**：一个外卖员获得时间暂停能力，用来送外卖和打脸富二代

**AI生成大纲要点**：
1. 开篇：主角被富二代羞辱，觉醒能力
2. 发展：利用能力送外卖，成为单王
3. 转折：能力被神秘组织发现
4. 高潮：与组织对抗，保护家人
5. 结局：成为守护者，能力升级

**人工调整**：
- 加入感情线（女主角是富二代妹妹）
- 增加喜剧元素（时间暂停时的尴尬场景）
- 强化爽点（每次打脸都有新花样）
