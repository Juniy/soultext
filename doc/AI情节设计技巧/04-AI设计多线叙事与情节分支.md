# AI设计多线叙事与情节分支

## 一、多线叙事的核心思路

### 多线叙事的价值
多线叙事让故事更有层次感和丰富度。所有分支都得服务主线和故事主题，不能是多余的；分支的起承转合要逻辑通顺，前面埋的伏笔后面一定要圆上 [1]。

### 多线叙事的核心原则
- 主线清晰，支线丰富
- 支线服务主线，不是独立故事
- 多线最终汇聚
- 控制支线数量和篇幅

## 二、多线叙事提示词模板

### 模板A：主线与支线设计
```
请为以下故事设计主线和支线：

【故事核心】[一句话概括故事]
【主角】[简要描述]
【预计篇幅】[总章节数]

【主线设计】
1. 主线目标：[主角的终极目标]
2. 主线冲突：[核心矛盾]
3. 主线阶段：[3-5个主要阶段]
4. 主线高潮：[最终对决/核心事件]
5. 主线结局：[最终结果]

【支线设计】
请设计2-4条支线：

支线1：
- 类型：[感情线/友情线/事业线/成长线]
- 涉及人物：[谁]
- 与主线关系：[如何服务主线]
- 起止章节：[第几章到第几章]
- 高潮章节：[第几章]
- 字数占比：[占总字数的百分比]

支线2：
- [同上格式]

【要求】
- 支线不能多余
- 支线之间有交叉点
- 支线在主线高潮前收尾
- 支线篇幅不超过主线
```

### 模板B：双线并行设计
```
请为以下故事设计双线并行的叙事：

【线A】[主角线]
【线B】[副线/反派线]

【并行方式】
- [ ] 交替叙事：A一章B一章
- [ ] 主次叙事：A为主，B穿插
- [ ] 汇聚叙事：A和B最终交汇

【并行设计】
1. **前期**（1-30%）：
   - A线：[进展]
   - B线：[进展]
   - 交汇点：[是否有交集]

2. **中期**（30-70%）：
   - A线：[进展]
   - B线：[进展]
   - 交汇点：[是否有交集]

3. **后期**（70-100%）：
   - A线：[进展]
   - B线：[进展]
   - 最终交汇：[如何汇合]

【信息差设计】
- A知道但B不知道：[信息]
- B知道但A不知道：[信息]
- 双方都不知道：[信息]
- 读者知道但角色不知道：[信息]
```

### 模板C：情节分支设计
```
请为以下情节设计分支选项：

【当前情节】[主角面临选择]
【选项数量】[2-3个]

【每个选项包含】
1. **选项内容**：[具体选择]
2. **短期后果**：[选择后的直接结果]
3. **长期影响**：[对后续剧情的影响]
4. **人物变化**：[对主角性格的影响]
5. **新冲突**：[引发的新矛盾]
6. **伏笔**：[埋下的新伏笔]

【要求】
- 每个选项都有利有弊
- 没有明显的"正确答案"
- 每个选项都能推动剧情
- 选择要符合人物性格
```

## 三、不同类型多线叙事

### 感情线与事业线并行
```
请设计感情线与事业线并行的叙事：

【主角】[简要描述]
【事业线】[事业目标和发展]
【感情线】[感情对象和发展]

【并行设计】
1. 事业线推进时，感情线如何发展
2. 感情线推进时，事业线如何发展
3. 事业与感情的冲突点
4. 事业与感情的互相促进
5. 最终如何平衡

【要求】
- 两条线不能割裂
- 有交叉和影响
- 不要一条线完全停顿
```

### 主角线与反派线并行
```
请设计主角线与反派线并行的叙事：

【主角线】[主角的目标和进展]
【反派线】[反派的目标和进展]

【并行设计】
1. 主角在做什么时，反派在做什么
2. 双方的计划如何碰撞
3. 信息差造成的戏剧效果
4. 最终对决的铺垫

【技巧】
- 反派线让读者看到主角看不到的
- 增加紧张感和期待感
- 反派不是纯粹的坏人
```

### 多角色视角并行
```
请设计多角色视角并行的叙事：

【角色A视角】[看到什么]
【角色B视角】[看到什么]
【角色C视角】[看到什么]

【并行设计】
1. 同一事件，不同视角
2. 信息差造成误会
3. 视角切换的时机
4. 视角切换的频率

【要求】
- 每个视角有独特信息
- 视角之间有信息差
- 切换自然不突兀
- 最终所有视角汇聚
```

## 四、情节分支管理

### 分支决策树
```
请为以下故事生成情节分支决策树：

【核心情节】[主要情节节点]
【分支深度】[2-3层]

【决策树格式】
节点1：[情节起点]
├── 选项A：[选择A]
│   ├── 选项A1：[子选择]
│   └── 选项A2：[子选择]
├── 选项B：[选择B]
│   ├── 选项B1：[子选择]
│   └── 选项B2：[子选择]
└── 选项C：[选择C]

【要求】
- 分支最终汇聚到主线
- 不要无限分叉
- 每个分支都有意义
```

### 分支合并技巧
```
请设计以下分支的合并方式：

【分支A】[一条故事线]
【分支B】[另一条故事线]
【合并点】[什么时候汇合]

【合并方式】
- [ ] 偶然相遇：两条线的人物意外相遇
- [ ] 因果关联：一条线的事件影响另一条线
- [ ] 共同目标：两条线的人物发现共同目标
- [ ] 外力推动：外部事件迫使两条线汇合

【要求】
- 合并要自然
- 合并后有新的冲突
- 合并点是一个小高潮
```

## 五、AI多线叙事避坑指南

### 常见错误
1. **支线过多**：读者记不住那么多线
2. **支线与主线无关**：支线是独立的故事
3. **支线抢戏**：支线比主线还精彩
4. **支线不收尾**：开了支线忘了收
5. **频繁切换**：视角切换太频繁

### AI常见问题
1. **逻辑混乱**：多线之间逻辑不通
2. **节奏失控**：支线拖慢主线节奏
3. **人物混淆**：多线人物太多
4. **信息过载**：读者跟不上

### 解决方法
- 控制支线数量（2-4条）
- 确保支线服务主线
- 定期检查支线进度
- 使用表格管理多线

## 六、实战案例

### 案例1：双雄线
**提示词**：
```
请设计双雄并行的叙事：
- 线A：正派主角，从弱到强
- 线B：反派主角，从强到疯狂
- 要求：两人命运交织，最终对决
```

**AI生成要点**：
- 前期：两人在不同地方成长
- 中期：两人开始接触，互相不知道身份
- 后期：发现对方身份，矛盾激化
- 高潮：最终对决，互相理解

### 案例2：事业与感情
**提示词**：
```
请设计事业线与感情线并行：
- 事业线：创业，面临破产危机
- 感情线：与合伙人的感情
- 要求：事业与感情互相影响
```

**AI生成要点**：
- 事业危机时，感情是支撑
- 感情危机时，事业是逃避
- 最终：事业成功，感情也修成正果
- 冲突点：事业需要裁员，对象是被裁的人

## 七、多线叙事检查清单

- [ ] 主线是否清晰？
- [ ] 支线数量是否合适？
- [ ] 支线是否服务主线？
- [ ] 多线是否有交叉点？
- [ ] 是否有信息差设计？
- [ ] 视角切换是否自然？
- [ ] 支线是否都有收尾？
- [ ] 最终是否汇聚？
