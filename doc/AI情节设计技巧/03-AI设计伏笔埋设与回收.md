# AI设计伏笔埋设与回收

## 一、伏笔设计的核心思路

### 伏笔是故事的暗线
明确标注伏笔："苏瑶吊坠与玉佩图案相似，预计第7章回收"，哪怕现在不展开，AI也会在描写时留痕，后期绝不强行圆设定 [1]。

### 伏笔的核心原则
好的伏笔让读者在揭晓时恍然大悟："原来前面那个细节是这个意思！"而不是觉得突兀。

## 二、伏笔设计提示词模板

### 模板A：伏笔规划
```
请为以下故事规划伏笔系统：

【故事大纲】[简要大纲]
【故事长度】[预计章节数]

【伏笔规划】
请设计5-8个伏笔，每个包含：

1. **伏笔编号**：[1-8]
2. **伏笔内容**：[具体是什么]
3. **埋设位置**：[第几章，什么场景]
4. **埋设方式**：[对话中/描写中/事件中]
5. **回收位置**：[第几章]
6. **回收方式**：[如何揭示]
7. **重要性**：[核心/重要/次要]
8. **关联情节**：[与什么情节相关]

【要求】
- 伏笔要自然不刻意
- 回收时要让读者恍然大悟
- 核心伏笔与主线相关
- 次要伏笔增加趣味
```

### 模板B：伏笔埋设生成
```
请为以下情节生成伏笔埋设：

【当前章节】[第几章]
【需要埋设的伏笔】[具体伏笔内容]
【场景】[当前场景]

【埋设方式】
- [ ] 对话中暗示：角色无意中提到
- [ ] 描写中隐藏：环境描写中包含线索
- [ ] 事件中埋设：某个事件中暗含信息
- [ ] 物品中隐藏：某个物品有特殊含义
- [ ] 行为中暗示：角色的某个行为有深意

【要求】
1. 伏笔要自然，不能太刻意
2. 读者第一遍读不会注意
3. 回顾时能发现
4. 与当前场景融合
5. 字数控制在50-100字
```

### 模板C：伏笔回收生成
```
请为以下伏笔设计回收方式：

【伏笔内容】[具体伏笔]
【埋设位置】[第几章埋的]
【当前进度】[第几章]

【回收方式】
- [ ] 直接揭示：角色发现真相
- [ ] 间接揭示：通过事件暗示
- [ ] 对比揭示：前后对比发现
- [ ] 多伏笔汇聚：多个伏笔指向同一真相

【回收要求】
1. 回收时机要合适（不能太早也不能太晚）
2. 回收方式要有冲击力
3. 让读者恍然大悟
4. 回收后推动剧情发展
5. 与其他伏笔可能有关联

【输出】
生成回收场景的具体描写。
```

## 三、不同类型伏笔设计

### 身份伏笔
```
请设计身份相关的伏笔：

【真实身份】[角色的真实身份]
【表面身份】[角色表现出的身份]

【伏笔设计】
1. 名字暗示：[名字中的线索]
2. 技能暗示：[不该有的能力]
3. 知识暗示：[不该知道的信息]
4. 习惯暗示：[与表面身份不符的习惯]
5. 反应暗示：[对某些事物的异常反应]

【要求】
- 每个伏笔单独看不奇怪
- 汇聚在一起指向真相
- 有3-5个伏笔
```

### 预言伏笔
```
请设计预言/占卜类伏笔：

【预言内容】[预言说了什么]
【真实含义】[预言的真正含义]

【伏笔设计】
1. 预言的表面含义：[角色理解的]
2. 预言的隐藏含义：[真正的含义]
3. 预言的实现方式：[如何应验]
4. 预言的误导：[故意误导的部分]

【要求】
- 预言要有多重解读
- 实现方式要出人意料
- 不是简单的"预言成真"
```

### 物品伏笔
```
请设计物品相关的伏笔：

【物品】[具体物品]
【隐藏含义】[物品的真正意义]

【伏笔设计】
1. 物品的获得：[如何得到]
2. 物品的异常：[不寻常之处]
3. 物品的变化：[随剧情的变化]
4. 物品的揭示：[何时揭示真相]
5. 物品的象征：[象征什么]

【要求】
- 物品在剧情中有作用
- 不是纯装饰
- 揭示时有惊喜感
```

### 关系伏笔
```
请设计人物关系的伏笔：

【真实关系】[两人真正的关系]
【表面关系】[表现出的关系]

【伏笔设计】
1. 初识时的暗示：[第一次见面的异常]
2. 互动中的暗示：[日常互动的细节]
3. 第三方暗示：[他人的评价]
4. 对比暗示：[与其他人的对比]
5. 关键时刻的暗示：[危机时的反应]

【要求】
- 暗示要自然
- 不要太明显
- 揭示时读者能回想起来
```

## 四、AI伏笔管理系统

### 伏笔数据库
```
请为以下故事建立伏笔数据库：

【故事信息】[类型、大纲]

【数据库格式】
| 编号 | 伏笔内容 | 埋设章节 | 埋设方式 | 回收章节 | 回收方式 | 状态 | 重要性 |
|------|----------|----------|----------|----------|----------|------|--------|
| 1    |          |          |          |          |          | 未埋  | 核心   |
| 2    |          |          |          |          |          | 已埋  | 重要   |
| 3    |          |          |          |          |          | 已回收| 次要   |

【管理要求】
1. 每写完一章，更新伏笔状态
2. 标注"未埋/已埋/已回收/待回收"
3. 检查是否有遗漏的伏笔
4. 确保所有伏笔最终回收
```

### 伏笔检查
```
请检查以下故事的伏笔系统：

【已埋伏笔列表】[列出所有已埋伏笔]
【当前进度】[第几章]

【检查维度】
1. 是否有未回收的伏笔？
2. 伏笔是否快要过期？（埋太久读者忘了）
3. 是否需要追加新伏笔？
4. 伏笔之间是否有关联？
5. 是否有冲突的伏笔？

【建议】
给出具体的调整建议。
```

## 五、伏笔设计避坑指南

### 常见错误
1. **伏笔太明显**：读者一眼就看出来
2. **伏笔太隐蔽**：回收时读者完全不记得
3. **伏笔不回收**：埋了就忘了
4. **伏笔强行回收**：回收方式不合理
5. **伏笔过多**：读者记不住

### AI常见问题
1. **刻意埋伏笔**：为埋伏笔而埋伏笔
2. **伏笔与剧情无关**：伏笔不影响主线
3. **回收方式单一**：总是用对话揭示
4. **伏笔时间跨度太长**：读者已经忘了

### 解决方法
- 要求AI控制伏笔数量（5-8个核心伏笔）
- 要求AI确保伏笔自然融入剧情
- 定期检查伏笔状态
- 核心伏笔在30章内回收

## 六、实战案例

### 案例1：项链伏笔
**提示词**：
```
请设计一个项链相关的伏笔：
- 埋设：女主从小戴着的项链
- 回收：项链其实是打开密室的钥匙
- 要求：前期有3处暗示
```

**AI生成要点**：
- 埋设1：项链的图案与密室门上的图案相似
- 埋设2：项链材质特殊，不会生锈
- 埋设3：母亲临终前反复叮嘱"不要摘下项链"
- 回收：密室门前，主角无意中用项链比对

### 案例2：对话伏笔
**提示词**：
```
请设计一个对话中的伏笔：
- 埋设：反派说"我最讨厌背叛"
- 回收：反派其实曾经背叛过自己的师父
- 要求：对话要自然
```

**AI生成要点**：
- 埋设场景：反派教训手下时说的
- 表面含义：反派重视忠诚
- 隐藏含义：反派对背叛有心理阴影（因为自己背叛过）
- 回收：主角发现反派师父的死因

## 七、伏笔检查清单

- [ ] 伏笔数量是否合适（5-8个核心）？
- [ ] 伏笔是否自然融入剧情？
- [ ] 伏笔是否有多重含义？
- [ ] 回收时机是否合适？
- [ ] 回收方式是否有冲击力？
- [ ] 是否所有伏笔都计划回收？
- [ ] 读者是否能回想起伏笔？
- [ ] 伏笔是否服务于主线？
