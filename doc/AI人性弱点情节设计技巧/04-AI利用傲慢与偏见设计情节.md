# AI利用傲慢与偏见设计情节

## 一、傲慢与偏见的本质

### 傲慢的心理学基础
傲慢与偏见其实是人类中最本质的弱点 [1]。傲慢让人高估自己，低估他人，最终因轻视而失败。傲慢的核心是"我比你强"。

### 偏见的心理学基础
偏见让人用刻板印象看待他人，忽视个体差异。偏见的核心是"你们都一样"。

## 五、AI傲慢偏见避坑指南

### 常见错误
1. **傲慢太脸谱**：一出场就很傲慢
2. **偏见太简单**：没有形成原因
3. **改变太容易**：一下子就不傲慢了
4. **说教意味重**：像在讲道理

### 解决方法
- 傲慢要有背景
- 偏见要有成因
- 改变要有过程
- 通过故事展现

## 六、实战案例

### 案例：傲慢的天才
**提示词**：
```
请设计一个傲慢天才被打脸的情节：
- 角色：天才科学家，看不起他人
- 情境：遇到真正的问题
- 要求：展现傲慢如何导致失败
```

**AI生成要点**：
- 天才一直独来独往，看不起团队
- 遇到难题，独自研究失败
- 团队成员提出方案，天才不屑
- 天才的方案失败，团队的方案成功
- 天才认识到团队的力量
