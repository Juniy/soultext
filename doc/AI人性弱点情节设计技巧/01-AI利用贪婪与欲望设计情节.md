# AI利用贪婪与欲望设计情节

## 一、贪婪与欲望的本质

### 贪婪的心理学基础
贪婪是人类对资源、权力、财富的无限渴求。它让人失去理智，做出违背道德和理性的选择。贪婪的核心是"永不满足"——得到的越多，想要的越多。

### 欲望的类型
- **物质欲望**：金钱、珠宝、房产
- **权力欲望**：地位、控制、影响力
- **情感欲望**：占有、被爱、嫉妒
- **知识欲望**：秘密、真相、力量

## 二、贪婪驱动的情节设计

### 模板A：贪婪陷阱
```
请设计一个由贪婪驱动的情节：

【触发点】[什么激发了贪婪]
【角色】[被贪婪控制的人]
【目标】[贪婪的对象]

【情节设计】
1. **诱惑出现**：[什么诱惑了角色]
2. **理智挣扎**：[内心的矛盾]
3. **贪婪战胜理智**：[做出决定]
4. **短期获益**：[似乎成功了]
5. **欲望膨胀**：[想要更多]
6. **暴露/失败**：[贪婪的代价]
7. **最终结局**：[失去一切]

【要求】
- 贪婪有具体对象
- 过程有层次递进
- 结局有警示意义
- 让读者既理解又警醒
```

### 模板B：多人贪婪博弈
```
请设计一个多人因贪婪而博弈的情节：

【参与者】[列出参与者及各自贪婪目标]
【资源】[争夺的对象]
【规则】[博弈的规则]

【博弈过程】
1. **初始状态**：各方势力
2. **第一轮博弈**：试探和联盟
3. **背叛发生**：有人打破联盟
4. **局势升级**：手段越来越极端
5. **最终对决**：赢家通吃或两败俱伤

【要求】
- 每个参与者都有合理性
- 背叛有动机支撑
- 结局出人意料
- 展现人性的复杂
```

### 模板C：贪婪与道德的冲突
```
请设计一个贪婪与道德冲突的情节：

【角色】[有道德底线但有贪欲的人]
【诱惑】[巨大的利益]
【道德约束】[什么阻止他贪婪]

【冲突设计】
1. 发现机会：[巨大的利益出现]
2. 内心挣扎：[道德vs贪婪]
3. 小步试探：[先迈出一小步]
4. 底线突破：[第一次违背道德]
5. 一发不可收拾：[越来越贪婪]
6. 良心发现或彻底堕落：[两种结局]

【要求】
- 挣扎要真实
- 堕落有过程
- 让读者感同身受
```

## 三、不同场景中的贪婪情节

```
请设计一个职场贪婪情节：

【贪婪对象】[功法/法宝/秘境]

```

## 四、AI贪婪情节避坑指南

### 常见错误
1. **贪婪太明显**：角色一出场就很贪婪
2. **过程太快**：从正常到贪婪没有过渡
3. **结局太俗**：总是"恶有恶报"
4. **缺乏层次**：贪婪没有递进

### 解决方法
- 贪婪要有触发点
- 过程要有挣扎
- 结局可以开放
- 贪婪对象要具体

## 五、实战案例

### 案例：宝藏陷阱
**提示词**：
```
请设计一个由贪婪驱动的宝藏陷阱情节：
- 角色：探险队队长
- 诱惑：传说中的宝藏
- 要求：展现贪婪如何让人失去理智
```

**AI生成要点**：
- 发现宝藏，队员建议上报
- 队长想独吞，设计除掉队员
- 一个个除掉，最后只剩队长
- 宝藏是陷阱，队长被困
- 临死前看到队员的鬼魂
