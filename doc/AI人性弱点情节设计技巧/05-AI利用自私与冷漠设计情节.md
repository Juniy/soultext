# AI利用自私与冷漠设计情节

## 一、自私与冷漠的本质

### 自私的心理学基础
自私是过度关注自身利益，忽视他人需求。人性自带弱点，容易自我关注自身利益 [1]。自私的核心是"我最重要"。

### 冷漠的心理学基础
冷漠是对他人苦难的漠视，缺乏同理心。冷漠的核心是"与我无关"。

## 二、自私驱动的情节设计

### 模板A：自私的代价
```
请设计一个自私付出代价的情节：

【自私者】[姓名、自私的表现]
【情境】[需要做出选择]
【自私选择】[选择了什么]

【情节设计】
1. **利益诱惑**：[什么利益]
2. **自私选择**：[牺牲他人利益]
3. **短期获益**：[似乎成功了]
4. **关系破裂**：[失去信任]
5. **孤立无援**：[需要帮助时无人相助]
6. **最终失败**：[自私导致失败]
7. **醒悟或继续**：[两种结局]

【要求】
- 自私有具体表现
- 代价要层层递进
- 让读者既恨又理解
```

```

【对比设计】
1. 面对利益：[不同选择]
2. 短期结果：[自私者更好]
3. 中期结果：[无私者更好]
4. 长期结果：[无私者远胜]
5. 最终对比：[价值观的碰撞]

【要求】
- 对比要鲜明
- 不要简单说教
- 让读者自己判断
```

## 三、冷漠驱动的情节设计

### 模板A：冷漠的连锁反应
```
请设计一个冷漠导致连锁反应的情节：

【冷漠者】[对他人苦难漠视]
【受害者】[需要帮助的人]
【旁观者】[其他冷漠的人]

【情节设计】
1. **求助出现**：[有人需要帮助]
2. **冷漠拒绝**：[第一个冷漠者]
3. **连锁冷漠**：[其他人也冷漠]
4. **悲剧发生**：[受害者遭遇不幸]
5. **真相揭露**：[冷漠的后果]
6. **内疚或辩解**：[冷漠者的反应]

【要求】
- 展现群体冷漠
- 个体在群体中的责任
- 有社会警示意义
```

### 模板B：冷漠的融化
```
请设计一个从冷漠到温暖的情节：

【初始状态】[非常冷漠]
【触发事件】[什么触动了内心]
【改变过程】[如何一步步改变]

【融化设计】
1. 冷漠表现：[对他人漠不关心]
2. 意外接触：[被迫接触某人]
3. 内心触动：[被某事打动]
4. 开始关心：[小举动]
5. 深入卷入：[无法置身事外]
6. 完全改变：[成为温暖的人]

【要求】
- 触动要真实
- 改变要有层次
- 最终温暖要可信
```

## 五、AI自私冷漠避坑指南

### 常见错误
1. **自私太明显**：一出场就很自私
2. **冷漠太绝对**：没有任何温情
3. **改变太突然**：一下子就不自私了
4. **缺乏层次**：自私没有递进

### 解决方法
- 自私要有触发点
- 冷漠要有原因
- 改变要有过程
- 加入复杂情感

## 六、实战案例

### 案例：电梯困境
**提示词**：
```
请设计一个电梯困境中的自私情节：
- 场景：电梯故障，氧气有限
- 角色：5个陌生人
- 要求：展现自私与无私的冲突
```

**AI生成要点**：
- 电梯故障，手机没信号
- 氧气逐渐稀薄
- 有人提议牺牲弱者
- 有人坚决反对
- 最终发现氧气其实足够
- 自私者的内疚
