# AI描写日常与生活场景

## 一、AI描写日常场景的核心思路

### 为什么用AI描写日常场景
- **生活气息**：AI能生成充满烟火气的日常描写
- **细节丰富**：提供大量生活细节选择
- **真实感强**：让读者感到亲切和真实
- **调节节奏**：在紧张剧情间提供缓冲

### 日常描写的核心原则
日常场景不是流水账，而是通过生活细节展现人物性格、推动关系发展、为后续剧情埋下伏笔。

## 二、日常场景提示词模板

### 模板A：居家生活场景
```
请生成一段居家生活场景：

【角色】[姓名、性格、家庭状况]
【场景】[客厅/厨房/卧室等]
【时间】[早晨/中午/傍晚/深夜]
【情绪基调】[温馨/平淡/压抑等]

【要求】
1. **环境细节**：家具、物品、装饰
2. **生活动作**：做饭、打扫、休息
3. **感官体验**：食物香气、阳光温度
4. **人物互动**：与家人/室友的互动
5. **性格展现**：通过日常习惯展现性格

【风格】
- [ ] 温馨治愈
- [ ] 烟火气息
- [ ] 平淡真实

【禁忌】
- 不要流水账
- 不要过于文艺
- 不要脱离人物性格
```

### 模板B：职场工作场景
```
请生成一段职场工作场景：

【角色】[姓名、职位、性格]
【场景】[办公室/会议室/工位]
【事件】[开会/加班/摸鱼/冲突]

【要求】
1. **职场氛围**：忙碌/轻松/紧张
2. **同事互动**：闲聊/合作/竞争
3. **工作细节**：电脑、文件、电话
4. **职场政治**：暗示权力关系
5. **人物状态**：疲惫/充实/焦虑

【技巧】
- 用具体的工作细节
- 展现职场人际关系
- 暗示人物的职业性格
```

### 模板C：街头巷尾场景
```
请生成一段街头巷尾的场景：

【地点】[菜市场/夜市/小巷/公园]
【时间】[早晨/中午/傍晚/深夜]
【角色】[在场的人物]

【要求】
1. **环境氛围**：热闹/冷清/嘈杂
2. **人物群像**：路人、摊贩、老人、孩子
3. **声音细节**：叫卖、聊天、车声
4. **气味细节**：食物、烟味、花香
5. **生活气息**：展现真实的城市生活

【技巧】
- 用具体的人物和对话
- 展现地方特色
- 有画面感和声音感
```

### 模板D：饮食场景
```
请生成一段饮食场景：

【食物】[具体菜品]
【场景】[餐厅/家里/路边摊]
【角色】[吃饭的人及关系]

【要求】
1. **食物描写**：色香味形
2. **制作过程**：如在家做饭
3. **进食动作**：怎么吃、什么反应
4. **对话互动**：边吃边聊
5. **情感暗示**：通过食物展现关系

【技巧】
- 用五感描写食物
- 通过吃的方式展现性格
- 食物承载情感和记忆
```

## 三、不同类型日常场景

### 清晨场景
```
请描写一个清晨场景：

【角色】[姓名、职业、状态]
【场景】[家中/路上/办公室]

【清晨元素】
1. 光线变化：从暗到亮
2. 声音变化：从安静到嘈杂
3. 温度变化：从凉到暖
4. 人物状态：从困到清醒
5. 日常仪式：刷牙、咖啡、早餐

【要求】
- 有生活气息
- 展现角色的日常习惯
- 为一天的剧情做铺垫
```

### 深夜场景
```
请描写一个深夜场景：

【角色】[姓名、状态]
【场景】[家中/办公室/街头]

【深夜元素】
1. 安静的氛围
2. 孤独感
3. 思绪万千
4. 窗外的城市
5. 不眠的原因

【要求】
- 展现角色的内心世界
- 与白天的反差
- 为后续剧情埋伏笔
```

### 雨天场景
```
请描写一个雨天场景：

【雨的类型】[细雨/暴雨/雷雨]
【场景】[室内/室外]
【角色】[姓名、情绪]

【雨天元素】
1. 雨声的变化
2. 空气的湿润
3. 视线的模糊
4. 人们的反应
5. 情绪的映射

【要求】
- 雨天氛围与情绪呼应
- 有具体的感官细节
- 展现雨天特有的生活状态
```

### 节日场景
```
请描写一个节日场景：

【节日】[春节/中秋/圣诞等]
【场景】[家中/街头/聚会]
【角色】[在场的人物及关系]

【节日元素】
1. 装饰和布置
2. 食物和饮品
3. 活动和仪式
4. 人物互动
5. 情感氛围

【要求】
- 展现节日特有的氛围
- 通过节日展现人物关系
- 有温馨或孤独的反差
```

## 四、日常场景的细节技巧

### 通过物品展现人物
```
请通过日常物品展现人物性格：

【角色】[简要描述]
【场景】[角色的房间/工位/随身物品]

【要求】
选择5-10个物品，每个物品展现一个性格侧面：
1. 物品：[具体物品] → 暗示：[性格特点]
2. 物品的摆放方式
3. 物品的新旧程度
4. 物品的不协调之处

【原则】
- 不要直接说"他很整洁"
- 通过物品让读者自己判断
- 物品要有故事
```

### 通过日常习惯展现人物
```
请通过日常习惯展现人物性格：

【角色】[简要描述]

【要求】
设计5个日常习惯，每个展现一个性格特点：
1. 早晨的习惯
2. 饮食的习惯
3. 工作的习惯
4. 休息的习惯
5. 睡前的习惯

【原则】
- 习惯要具体不笼统
- 习惯要有原因
- 习惯在剧情中有作用
```

### 通过日常对话展现关系
```
请通过日常对话展现人物关系：

【角色A】[姓名、与B的关系]
【角色B】[姓名、与A的关系]
【场景】[日常场景]

【要求】
1. 对话内容是日常琐事
2. 但潜台词展现关系
3. 有默契和了解
4. 有小摩擦和小甜蜜
5. 展现关系的真实状态

【禁忌】
- 不要过于甜蜜
- 不要过于戏剧化
- 要有生活气息
```

## 五、AI日常描写避坑指南

### 常见错误
1. **流水账**：起床→刷牙→吃饭→上班
2. **过度描写**：每个细节都写
3. **缺乏目的**：日常场景没有作用
4. **脱离人物**：日常不符合人物性格
5. **过于平淡**：日常也要有看点

### AI常见问题
1. **模板化**：常见的日常描写套路
2. **缺乏生活气息**：AI的生活经验有限
3. **过于完美**：生活不够真实
4. **不接地气**：缺乏烟火气

### 解决方法
- 要求AI加入不完美细节
- 要求AI通过日常展现人物
- 人工加入真实的生活经验
- 控制日常场景的篇幅

## 六、实战案例

### 案例1：独居青年的早晨
**提示词**：
```
请描写一个独居程序员的早晨：
- 角色：28岁，社恐，独居
- 场景：出租屋
- 要求：通过日常展现性格和生活状态
```

**AI生成要点**：
- 闹钟响了三次才起
- 房间窗帘紧闭
- 早餐是昨晚的外卖
- 打开电脑先看手机
- 出门前犹豫要不要社交

### 案例2：家庭晚餐
**提示词**：
```
请描写一家人的晚餐场景：
- 角色：父母、两个孩子
- 场景：普通家庭餐桌
- 要求：通过晚餐展现家庭关系
```

**AI生成要点**：
- 妈妈做饭，爸爸摆碗筷
- 哥哥抢妹妹的菜
- 爸爸问学习，妈妈打圆场
- 电视声音作为背景
- 饭后的分工（洗碗/写作业）
