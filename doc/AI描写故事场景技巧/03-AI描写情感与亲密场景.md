# AI描写情感与亲密场景

## 一、AI描写情感场景的核心思路

### 为什么用AI描写情感场景
- **情感微澜捕捉**：AI能捕捉细微的情感变化
- **张力拉满**：生成张力十足的互动文案
- **多种风格**：支持都市甜宠、古言虐恋、暧昧拉扯等
- **细节丰富**：提供大量情感细节选择

### 情感描写的核心原则
情感场景不是直接说"我爱你"或"我很伤心"，而是通过细节、动作、环境让读者自己感受情感。

## 二、情感场景提示词模板

### 模板A：暧昧拉扯场景
```
请生成一段暧昧拉扯的场景：

【角色A】
- 姓名：[姓名]
- 对B的感情：[暗藏/试探/克制]
- 性格：[性格特点]

【角色B】
- 姓名：[姓名]
- 对A的感情：[不知情/装不知道/也有好感]
- 性格：[性格特点]

【场景】[时间、地点]
【关系现状】[朋友/同事/陌生人等]

【暧昧要求】
1. 眼神交汇又闪躲
2. 不经意的身体接触
3. 话里有话的对话
4. 心跳加速的瞬间
5. 克制与冲动之间

【风格】
- [ ] 甜而不腻
- [ ] 暧昧不明
- [ ] 拉扯感强

【禁忌】
- 不要直接表白
- 不要过于油腻
- 不要突然亲上去
```

### 模板B：表白场景
```
请生成一段表白场景：

【表白方】[姓名、性格、准备程度]
【被表白方】[姓名、性格、可能的反应]
【场景】[时间、地点、氛围]
【表白方式】[直接/含蓄/意外]

【要求】
1. 表白前的紧张铺垫
2. 表白时的犹豫和勇气
3. 对方的反应（惊讶/沉默/感动）
4. 双方的情感爆发
5. 结果（接受/拒绝/未确定）

【禁忌】
- 不要过于狗血
- 不要过于完美
- 不要过于文艺
```

### 模板C：虐心场景
```
请生成一段虐心场景：

【角色A】[姓名、痛苦来源]
【角色B】[姓名、痛苦来源]
【虐心类型】[误会/分离/牺牲/背叛]

【虐心要求】
1. 情感积累：先甜后虐更有冲击
2. 冲突爆发：矛盾激化的瞬间
3. 痛苦展现：不是哭，而是更深的痛
4. 无力感：想改变但无法改变
5. 余韵：虐完后的余波

【虐心层次】
- 表面冲突 → 深层矛盾 → 情感撕裂
- 不要一上来就最虐
- 层层递进

【禁忌】
- 不要为虐而虐
- 不要逻辑不通
- 不要人物OOC
```

### 模板D：重逢场景
```
请生成一段重逢场景：

【角色A】[姓名、分离后的变化]
【角色B】[姓名、分离后的变化]
【分离原因】[为什么分开]
【分离时长】[多久]

【重逢要求】
1. 重逢前的期待/不安
2. 看到对方的第一眼
3. 外表变化带来的冲击
4. 第一句话/第一个动作
5. 情感的爆发或克制

【风格】
- [ ] 热泪盈眶型
- [ ] 欲言又止型
- [ ] 假装平静型
- [ ] 相对无言型
```

### 模板E：告别场景
```
请生成一段告别场景：

【告别方】[姓名、告别原因]
【被告别方】[姓名、反应]
【告别类型】[永久/暂时/意外]

【告别要求】
1. 告别前的最后相处
2. 告别的方式（直接/间接/不辞而别）
3. 对方的发现和反应
4. 留下的东西（信/物品/记忆）
5. 告别后的余韵

【禁忌】
- 不要过于煽情
- 不要套路化
- 不要强行催泪
```

## 三、不同类型情感描写

### 甜蜜场景
```
请生成一段甜蜜场景：

【角色】[两人关系]
【甜蜜来源】[日常/特殊事件/意外]

【要求】
- 通过小细节展现甜蜜
- 不要过于腻歪
- 有生活气息
- 让读者会心一笑
```

### 争吵场景
```
请生成一段情侣争吵场景：

【争吵原因】[表面原因]
【深层原因】[真正的问题]
【角色A立场】[立场]
【角色B立场】[立场]

【要求】
1. 从小事开始
2. 逐步升级
3. 翻旧账
4. 伤人的话
5. 沉默或爆发
6. 后悔或坚持
```

### 守护场景
```
请生成一段守护场景：

【守护者】[姓名、能力、代价]
【被守护者】[姓名、处境]
【危险来源】[什么威胁]

【要求】
- 守护者默默付出
- 被守护者不知情或后知后觉
- 守护的代价
- 被发现时的反应
```

## 四、情感场景的感官描写

### 通过触觉展现情感
```
请通过触觉描写展现以下情感：

【情感类型】[爱/思念/不舍/心痛]
【场景】[具体场景]

【触觉元素】
1. 温度：体温的传递
2. 质感：手心的触感
3. 力度：拥抱的力度
4. 湿度：泪水、汗水
5. 痛感：心口的疼痛

【要求】
- 用触觉代替直接说"我爱你"
- 细节要具体
- 符合场景氛围
```

### 通过环境映射情感
```
请通过环境映射以下情感：

【情感】[具体情感]
【场景】[当前场景]

【要求】
- 环境与情感一致或形成反差
- 用天气、光线、声音暗示情感
- 不要直接说"气氛很悲伤"
```

## 五、AI情感描写避坑指南

### 常见错误
1. **直接陈述**："她很爱他" → 应该通过细节展现
2. **过度煽情**：哭得稀里哗啦，失去真实感
3. **狗血套路**：失忆、车祸、绝症
4. **油腻对话**：土味情话满天飞
5. **OOC**：人物性格突变

### AI常见问题
1. **模板化**：常见的情感套路
2. **过于文艺**：不接地气
3. **缺乏层次**：情感没有递进
4. **不协调**：情感与人物不符

### 解决方法
- 要求AI通过细节展现情感
- 要求AI控制煽情程度
- 要求AI加入不完美细节
- 人工检查是否符合人物

## 六、实战案例

### 案例1：暗恋被发现
**提示词**：
```
请描写暗恋被发现的场景：
- 角色：内向的女生，暗恋同桌男生
- 场景：教室，放学后只剩两人
- 发现方式：日记本掉落被捡起
- 要求：展现从被发现到承认的过程
```

**AI生成要点**：
- 日记本掉落的瞬间
- 女生的慌张（脸红、手抖）
- 男生的反应（先惊讶后沉默）
- 尴尬的沉默
- 女生鼓起勇气承认

### 案例2：久别重逢
**提示词**：
```
请描写久别重逢的场景：
- 角色：分手三年的恋人
- 场景：朋友婚礼上偶遇
- 要求：表面平静，内心翻涌
```

**AI生成要点**：
- 远远看到对方
- 假装没看见
- 被朋友介绍时握手
- 手心的温度
- 眼神交汇又移开
- 敬酒时说的"好久不见"
